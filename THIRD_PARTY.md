# Third-party data and assets

| What | Source | License |
| --- | --- | --- |
| Airports & runways (`src/web/data/airports.json`, `runways.json`) | [OurAirports](https://ourairports.com/data/) | Public domain |
| Coastlines, borders, lakes (`src/web/data/world.json`) | [Natural Earth](https://www.naturalearthdata.com/) 1:50m | Public domain |
| Roboto Condensed font | Google Fonts | SIL Open Font License 1.1 |
| Share Tech Mono font | Google Fonts | SIL Open Font License 1.1 |
| Default radio stations | [SomaFM](https://somafm.com/) streams (listener-supported) | Streamed, not redistributed |
